### 3.1 跨端一致性测试向量（本任务必产出）

**问题**：客户端（`src-tauri`）会复刻同一套 v5 派生算法（主方案 §11.6），两端是独立实现。各自的单测通过**不能证明两端算出同一个值** —— 命名空间笔误、大小写差异、拼接顺序颠倒都会静默分裂会话，且爆炸点在数周后的联调期，极难排查。

**机制**：生成命名空间后，立即产出一组**固定测试向量**，作为跨端对齐的唯一基准：

```bash
# 一次性生成（在填好 CONV_NAMESPACE_STR 并编译通过后运行）
cargo run --example gen_session_uuid_vectors 2>/dev/null || python - <<'PY'
import uuid

NS = uuid.UUID("<§3 生成的命名空间>")   # ← 替换

def single_session_uuid(a: uuid.UUID, b: uuid.UUID) -> str:
    lo, hi = sorted([a, b])
    return str(uuid.uuid5(NS, f"{lo}:{hi}"))

CASES = [
    ("symmetric_pair",   "00000000-0000-0000-0000-000000000001", "00000000-0000-0000-0000-000000000002"),
    ("reversed_input",   "00000000-0000-0000-0000-000000000002", "00000000-0000-0000-0000-000000000001"),  # 期望与上行相同
    ("self_session",     "00000000-0000-0000-0000-000000000003", "00000000-0000-0000-0000-000000000003"),
    ("nil_and_value",    "00000000-0000-0000-0000-000000000000", "ffffffff-ffff-ffff-ffff-ffffffffffff"),
    ("case_variant",     "00000000-0000-0000-0000-000000000004", "00000000-0000-0000-0000-000000000005"),  # 客户端另测大写输入
]

for name, a, b in CASES:
    print(f'{name}: {single_session_uuid(uuid.UUID(a), uuid.UUID(b))}')
PY
```

把输出整理为 `crates/common/testdata/session_uuid_vectors.json`：

```json
{
  "namespace": "<命名空间>",
  "cases": [
    { "name": "symmetric_pair", "a": "...", "b": "...", "expected": "..." },
    { "name": "reversed_input", "a": "...", "b": "...", "expected": "与 symmetric_pair 相同" },
    { "name": "self_session",   "a": "...", "b": "...", "expected": "..." }
  ]
}
```

**消费方式**：

- 服务端：`session_uuid.rs` 的单测读入该 JSON，逐条断言（`serde_json` 已在 dev-dependencies）
- 客户端（任务 07）：**复制同一份 JSON** 到 `src-tauri/testdata/`（两个仓库独立，物理拷贝），用同一组断言复刻

> 向量文件随任务 01 提交进服务端仓库。它的地位等同 `CONV_NAMESPACE` 本身 —— 后续任何"两端派生不一致"的排查，第一步就是核对这份文件是否两端同版。

### 5.2 新增 `crates/common/src/utils/session_uuid.rs`

```rust
//! 会话标识派生。
//!
//! 单聊: 由用户对规范化后经 UUID v5 确定性派生, (A,B) 与 (B,A) 恒等;
//! 群聊: 不派生, 直接使用 group_uuid 作为 session_uuid。

use once_cell::sync::Lazy;
use uuid::Uuid;

use crate::config_str::CONV_NAMESPACE_STR;

/// 命名空间常量(启动时解析一次)。
static CONV_NAMESPACE: Lazy<Uuid> =
    Lazy::new(|| Uuid::parse_str(CONV_NAMESPACE_STR).expect("CONV_NAMESPACE_STR 非法"));

/// 单聊会话标识: 由用户对派生, 双向对称。
///
/// - 规范化: 比较使用字节序(`as_bytes`), 与字符串大小写写法无关
///   (`Uuid::parse_str` 本身大小写不敏感, 解析后即为统一形态)
/// - 拼接: `{小uuid}:{大uuid}`, 分隔符 `:` 不会出现在 uuid 文本中, 无歧义
pub fn single_session_uuid(a: &Uuid, b: &Uuid) -> Uuid {
    let (lo, hi) = if a.as_bytes() <= b.as_bytes() { (a, b) } else { (b, a) };
    Uuid::new_v5(&CONV_NAMESPACE, format!("{lo}:{hi}").as_bytes())
}

/// 群聊会话标识: 恒等映射, group_uuid 即 session_uuid。
///
/// 提供此函数是为了让调用方对"单聊要派生 / 群聊直接用"的分支有统一的表达,
/// 也避免调用方散落硬编码。
pub const fn group_session_uuid(group_uuid: Uuid) -> Uuid {
    group_uuid
}

#[cfg(test)]
mod tests {
    use super::*;

    const A: Uuid = Uuid::nil();
    const B: Uuid = Uuid::from_u128(1);

    #[test]
    fn symmetric() {
        assert_eq!(single_session_uuid(&A, &B), single_session_uuid(&B, &A));
    }

    #[test]
    fn self_session_is_stable() {
        let s = single_session_uuid(&A, &A);
        assert_eq!(s, single_session_uuid(&A, &A));
        assert_ne!(s, A); // 自会话标识 != 用户自身 uuid
    }

    #[test]
    fn different_pairs_differ() {
        let c = Uuid::from_u128(2);
        assert_ne!(single_session_uuid(&A, &B), single_session_uuid(&A, &c));
    }

    #[test]
    fn case_insensitive_parse_then_same_session() {
        // 大小写两种写法解析后派生结果一致
        let lo = "00000000-0000-0000-0000-000000000000";
        let hi = "00000000-0000-0000-0000-000000000001";
        let s1 = single_session_uuid(&Uuid::parse_str(lo).unwrap(), &Uuid::parse_str(hi).unwrap());
        let s2 = single_session_uuid(
            &Uuid::parse_str(&hi.to_uppercase()).unwrap(),
            &Uuid::parse_str(lo).unwrap(),
        );
        assert_eq!(s1, s2);
    }

    #[test]
    fn group_identity() {
        let g = Uuid::from_u128(42);
        assert_eq!(group_session_uuid(g), g);
    }
}
```

> **为什么不用 `uuid!` 宏定义 const**：主方案 §5.1 用了 `uuid!(...)` 宏写法，但该宏对 feature 的要求存在版本差异。这里改用 `OnceCell::Lazy + parse_str`（common 已依赖 `once_cell`），行为等价且零 feature 风险 —— 这是对主方案的一处**实现层修正**，语义不变。
>
> **单测位置说明**：上面把单测内联在模块里；如果团队倾向独立测试文件，等价迁移到 `crates/common/tests/session_uuid_test.rs`（该目录已有 `utils_test.rs` 先例）。二选一，不要两处都放。
