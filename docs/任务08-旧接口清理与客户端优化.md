## 4. `/msg/get_chat_record` 入参 `session_uuid` 化

### 4.1 现状与问题

`select_chat_by_limit`（任务 02 修复后）仍是**双向 OR** 查询：

```sql
where (send_user = #{a} and recv_user = #{b}) or (send_user = #{b} and recv_user = #{a})
order by id limit #{size} offset #{start}
```

分区表上无 `session_uuid` 等值条件 → **跨 16 分区扫描**。旧索引已删，等于全分区 seq scan。

### 4.2 改造：新增可选参数，零契约破坏

```
POST /msg/get_chat_record/{uuid}        ← 旧: friend_uuid(保留, 内部派生)
Body: { "session_uuid": "...",          ← 新: 可选, 直达会话
        "page_num": 0, "page_size": 10 }
```

service 逻辑：

```rust
pub async fn get_chat_by_limit(
    rb: &RBatis,
    me: &str,
    friend_uuid: String,          // path 参数(旧)
    base_page: BasePageDTO,       // 扩展: 内含可选 session_uuid
) -> Result<String, anyhow::Error> {
    let me_uuid: Uuid = me.parse()?;
    // 优先 Body 的 session_uuid; 缺省时由旧参数派生(兼容)
    let session_uuid = match base_page.session_uuid {
        Some(s) => s.parse::<Uuid>()?,
        None => {
            let friend: Uuid = friend_uuid.parse()?;
            common::utils::session_uuid::single_session_uuid(&me_uuid, &friend)
        }
    };
    let res = ChatMessageRecord::select_by_session_paged(
        rb, &session_uuid, start, size,
    ).await?;
    ...
}
```

新查询（entity）：

```rust
/// 按会话分页翻历史(分区剪枝 + 索引扫描)。
#[rbatis::py_sql(
    "select * from chat_message_record
     where session_uuid = #{session_uuid}
     order by id limit #{size} offset #{start}"
)]
async fn select_by_session_paged_inner(
    rb: &dyn Executor, session_uuid: &Uuid, start: u32, size: u32,
) -> Vec<ChatMessageRecord> {}
```

`BasePageDTO` 加 `session_uuid: Option<String>` 字段（`#[serde(default)]`，旧客户端不传不影响）。

> **顺手收益**：双向 OR 判会话在单聊查询里彻底消失 —— 缺陷 M 的最后一处残留清零。

## 5. 客户端 HTTP `Client` 复用

### 5.1 `api_controller.rs`（`src-tauri/src/cmd/`）

现状（`api_controller.rs:26` / `:42` / `:66` 等每个函数）：

```rust
let client = Client::new();   // 每次调用新建 → 每次全新 TCP+TLS 握手(约 3 RTT)
```

改为（标准库 `OnceLock`，零新依赖）：

```rust
use std::sync::OnceLock;
use reqwest::Client;

/// 全局共享 Client: 连接池 + keep-alive 复用, 单次请求约 1 RTT。
fn http_client() -> &'static Client {
    static CLIENT: OnceLock<Client> = OnceLock::new();
    CLIENT.get_or_init(Client::new)
}

pub async fn get_request(url: String) -> Result<ApiResponse, String> {
    let client = http_client().clone();   // Client 内部是 Arc, clone 零成本
    ...
}
```

### 5.2 全部调用点替换

```bash
rg -n "Client::new\(\)" src-tauri/src/     # 逐一替换
```

重点文件：`api_controller.rs`（get/post/put）、`api_service.rs`（upload 系列 —— 上传用 `Client::new().builder()...` 的若带定制超时，保留定制但复用基础实例或单独静态化，按实际情况处理）。

> `reqwest::Client` 线程安全、内部连接池默认开启 —— 全局单例是官方推荐用法。**注意**：不要在 Tauri command 里持有 `&'static Client` 的可变包装，clone 使用即可。
